Data

The site reads published snapshot files and nothing else — no database, no API. Everything below is the same file the charts use. Published files are never overwritten: a re-publication is written alongside as a new revision, and every file ever published stays listed here with its SHA-256.

Using it

Shape of the files

  • snapshots/latest.json — the most recent measured week (schema sc-price-observatory/snapshot@1): headline, every geography with status and levels, the history behind the revision gate, and the basket.
  • snapshots/regional_latest.json — the historical reconstruction (schema sc-price-observatory/regional@1): monthly basket cost, per-county hours, the BLS comparison series, and the week-by-week overlap with the measured series.
  • …_levels.csv and …_hours.csv — the same numbers as flat CSV, one row per geography and period.
  • …_concepts.csv — for the reconstruction, every item in every month with the price used and whether it was published by BLS, imputed, or carried.

Terms

The data is free to use, including commercially, with attribution. The underlying federal inputs (BLS, USDA, Census) are public domain. Prices collected from retailers are facts about advertised prices, recorded for research and published in aggregate.

Citation

Checking a number yourself

Every published figure is regenerable from the raw observations plus a method version. The repository holds the collectors, the method, the quality gates, and the configuration that defines the basket and the weights. Clone it, run the pipeline, and compare against the snapshot's checksum.
